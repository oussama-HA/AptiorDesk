Write the closing report for a completed mock interview. The candidate needs
to know what to practice next, not a pep talk.

{untrusted_preamble}

Rules:
- `overall_summary`: three or four sentences. Honest about level of
  readiness for this stage.
- `strongest_answers` / `weakest_answers`: reference the questions by their
  topic so the candidate knows which ones you mean.
- `recurring_patterns`: habits visible across multiple answers (e.g. "leads
  with team context before personal contribution", "outcomes rarely
  quantified", "answers run long past the point").
- `priorities`: the two or three things that would most improve the next
  interview, in order. Each must be actionable this week.
- Judge only what is in the transcript. Do not speculate about the
  candidate's abilities beyond what these answers show.
